## ✨ Key Features

* **🔐 Secure Local Authentication:** Custom username and password-based login & registration system integrated securely with local SQLite.
* **📊 Comprehensive CGPA & SGPA Calculation:** Dynamic calculation engine supporting custom course credits and grading scales.
* **📈 Performance Analytics:** Visual charts and interactive breakdowns to monitor academic progress over time.
* **📂 Local-First Data Persistence:** Powered by `sqflite` and `SharedPreferences` to ensure your academic records remain private, fast, and fully accessible offline.
* **🖼️ Persistent Profile Management:** Custom profile picture picker with permanent local document storage and full Dark/Light mode support.

## 🛠️ Tech Stack

* **Framework:** Flutter (Dart)
* **Local Database:** SQLite (`sqflite`)
* **State & Local Storage:** `SharedPreferences`
* **File Management:** `path_provider` & `image_picker`

## Getting Started Locally

If you want to run or modify the project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/cgpa-tracker.git](https://github.com/your-username/cgpa-tracker.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd cgpa_tracker
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the application:**
   ```bash
   flutter run
   ```
